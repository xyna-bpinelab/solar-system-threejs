# solar-system-threejs

Three.js を用いた、太陽系（太陽・水星〜海王星・地球の月）の公転・自転を可視化する 3D シミュレーション。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド
```

## 構成

```
src/
  config.js            物理比率・時間スケール・カメラの設定を集約
                        （SUN / PLANETS / MOON の定義データもここに置く）
  CelestialBody.js      天体（メッシュ・マテリアル・自転）を表すクラス
  scene.js              scene / camera / renderer / OrbitControls / resize 対応
  solarSystem.js        太陽・各惑星・月の階層構造とフレーム更新ロジック
  cameraController.js   「中心天体+仰角」視点の計算・追従
  gui.js                lil-gui コントロールパネル（時間・表示/拡大・視点）
  main.js               初期化とアニメーションループ
```

新しい惑星を追加したい場合は `config.js` の `PLANETS` 配列に1エントリ足すだけで、
`solarSystem.js` のループ・GUI の表示/拡大設定・視点の中心天体選択すべてに
自動的に反映される（コードの変更は不要）。

## コントロールパネル（lil-gui）

画面右上のパネルから以下を操作できる。

- **時間**: 一時停止 / 速度（日/秒）
- **天体ごとの表示・拡大設定**: 水星・金星・地球・月・火星・木星・土星・
  天王星・海王星のそれぞれについて、
  - **表示**: シミュレーション画面への表示/非表示チェックボックス
  - **サイズ倍率**: 距離は変えず見た目のサイズだけ誇張するスライダー
    （太陽は光源を兼ねるため常時表示・対象外）
- **視点（中心天体・仰角）**: 画面中心に置く天体を太陽〜海王星・月から選び、
  水平面からの仰角（-85°〜85°）を指定して見下ろし/見上げの角度を調整できる。
  選択した天体が公転で動いても、カメラごと平行移動して追従し続ける
  （マウスによる回転・ズームは引き続き有効）。

厳密な比率のままだと、俯瞰カメラの位置からは地球・月はほぼ1ピクセル以下
になり肉眼では見えない。まずは「中心天体」で見たい天体を選ぶか、
「拡大表示」のスライダーでサイズを誇張するのが確認の近道。

## スケール・速度パラメータについて

`src/config.js` に定義された `SUN` / `PLANETS` / `MOON` のデータがすべての基準値。

- **`radiusRatio` / `distanceRatio`**: 地球半径を基準にした厳密な比率
  （太陽 109、地球 1、月 0.27、太陽からの距離は水星 9,092 〜 海王星
  705,730、地球-月間 60、いずれも地球半径基準）をそのままロジックに使用
  している。
- **`config.scale.sizeMultiplier`**: 上記の厳密比率に掛け合わせる倍率で、
  既定値はすべて `1`（＝厳密な比率のまま）。小さな天体は太陽・木星等との
  比率上非常に視認しづらいため、GUI から天体ごとに大きくするだけで、
  距離関係を保ったまま拡大表示できる。
- **`config.visibility`**: 天体ごとの表示/非表示フラグ。GUI のチェック
  ボックスと直結しており、`solarSystem.applyVisibility()` がメッシュの
  `visible` に反映する。
- **`config.time.speed`**: 実時間1秒あたりに進めるシミュレーション上の
  日数。各惑星の公転周期（水星 87.97日 〜 海王星 60,182日）・自転周期
  （金星・天王星は逆行のため負の値）をそのまま `orbitDays` /
  `rotationDays` に保持し、この `speed` を掛けてアニメーションの進み方を
  制御する（`config.time.paused` で一時停止も可能）。
- **`config.camera` / マウス操作**: 既定カメラは内側の岩石惑星（水星〜
  火星）を見渡せる俯瞰位置。木星より外側は軌道距離が桁違いに大きいため、
  初期表示の画角には収まらない（「中心天体」でその惑星を選べば個別に
  観察できる）。OrbitControls によるズームイン/アウトも常に有効。
